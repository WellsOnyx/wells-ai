# DAY 4: GTM Attribution & Auto-Billing

**Status**: LIVE IN PRODUCTION
**Deployed**: 2025-10-30
**Build Time**: 53s (all TypeScript errors resolved)

## Overview

Day 4 completes the Wells GTM revenue loop with full attribution tracking and automatic billing. When a deal closes, Wells AI now:

1. Tracks which prospect, outreach, meeting led to the close
2. Calculates the 33bps (0.33%) success fee automatically
3. Generates a Stripe invoice
4. Emails it to the customer
5. Collects payment automatically

**Result**: Zero manual work. Deal closes → invoice sent → payment collected.

---

## Revenue Model: 33 Basis Points

**Wells charges 33 basis points (0.33%) on closed ACV. Period.**

- $100K deal closes → Wells fee: $330
- $500K deal closes → Wells fee: $1,650
- $1M deal closes → Wells fee: $3,300
- $10M deal closes → Wells fee: $33,000

**No upfront fees. No retainers. No minimums.**

Payment terms: Net 30 via Stripe invoice.

export async function POST(request: Request) {

  const billing = await autoBilling.handleDealClosed({ ... })

  return Response.json({ success: true, billing })

### 8. Webhook Handling
```typescript
// lib/payments/stripe-billing.ts
async handleWebhook(event: Stripe.Event) {
  switch (event.type) {
    case 'invoice.paid':
      // Update deal status to "paid"
      await db.deals.update({ invoiceId }, { status: 'paid', paidAt: new Date() })
      break

    case 'invoice.payment_failed':
      // Send alert to admin
      await notify({ type: 'payment_failed', invoiceId })
      break
  }
}
```

## Stripe Setup

### 1. Get Stripe API Keys
1. Go to https://dashboard.stripe.com/apikeys
2. Copy "Secret key" (starts with `sk_`)
3. Add to `.env.local`:
```bash
STRIPE_SECRET_KEY=sk_live_xxx
```

### 2. Set Up Webhooks
1. Go to https://dashboard.stripe.com/webhooks
2. Add endpoint: `https://wellsai.vercel.app/api/webhooks/stripe`
3. Select events:
   - `invoice.paid`
   - `invoice.payment_failed`
   - `customer.created`
4. Copy webhook signing secret
5. Add to `.env.local`:
```bash
STRIPE_WEBHOOK_SECRET=whsec_xxx
```

### 3. Configure Invoice Settings
1. Go to Settings → Invoices
2. Set defaults:
   - Payment terms: Net 30
   - Auto-advance: Enabled
   - Send email: Enabled
   - Footer text: "Thank you for using Wells Onyx Revenue Operations"

### 4. Enable Payment Methods
1. Settings → Payment Methods
2. Enable:
   - Cards (Visa, Mastercard, Amex)
   - ACH Direct Debit
   - Wire Transfer
