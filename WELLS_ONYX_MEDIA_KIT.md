## What We Do

Wells Onyx operates two complementary platforms:

### 1. Wells AI - Conversational Commerce Platform
A conversational interface that helps businesses:
- **Buyers:** Find and procure products/services (semiconductors, talent, equipment, supplies)
- **Sellers:** Discover customers and manage GTM campaigns
- **Transactions:** Process payments, escrow, and settlements via Grain & Vault

### 2. Grain & Vault - B2B Payment Infrastructure
- **GRAIN:** Auto-appreciating stablecoin backed 1:1 by USDC
- **Vault Treasury:** Escrow and instant settlement for B2B transactions
- **Fee:** 0.33% per transaction (vs 2-3% for cards)

## Use Cases for Affiliate Partners

### Example 1: Instacart Partnership
**Scenario:** Company needs office supplies + groceries delivered

**Flow:**
1. User asks Wells: "I need office snacks for 50 people"
2. Wells queries Instacart API (real-time pricing)
3. Shows options, user selects
4. Wells processes order via Instacart affiliate link
5. **Revenue:** Instacart earns sale, Wells earns 3-5% affiliate commission

### Example 2: Faire Partnership
**Scenario:** Retailer needs wholesale inventory

**Flow:**
1. User asks Wells: "I need 100 units of product XYZ"
2. Wells searches Faire catalog (API integration)
3. User purchases via Grain & Vault (instant settlement)
4. **Revenue:** Wells earns 0.33% transaction fee + 5-10% Faire affiliate

### Example 3: Amazon Business
**Scenario:** Enterprise buyer needs industrial supplies

**Flow:**
1. User asks Wells: "I need PPE equipment for construction site"
2. Wells shows Amazon Business catalog results
3. User orders through Wells interface
4. **Revenue:** Wells earns 1-3% Amazon affiliate commission
