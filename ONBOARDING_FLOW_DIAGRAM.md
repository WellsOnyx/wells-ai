## Conversation Depth Progression

```
Depth Level Guide:

0-2: SURFACE
     • Basic information exchange
     • No personal details shared
     • Transactional only

3-4: ENGAGED
     • Name, role, company shared
     • Pain points discussed
     • Goals articulated

5-6: TRUSTING
     • Financial info shared (bank connection)
     • Integration preferences discussed
     • Future planning together

7-8: PARTNERSHIP
     • Proactive collaboration
     • Wells anticipating needs
     • User delegating freely

9-10: INDISPENSABLE
      • Complete reliance on Wells
      • Deep integration into workflows
      • Can't imagine working without it

Target: Reach depth 7+ by message 20
```

## Decision Tree: First Message

```
User's First Message
        │
        ├─► Specific need (e.g., "I need to source...")
        │   └─► Wells: "On it. Tell me more..."
        │       └─► Jump directly to helping
        │
        ├─► General exploration (e.g., "What is this?")
        │   └─► Wells: "I'm Wells. I handle B2B transactions.
        │                What do you need?"
        │       └─► Brief intro, then ask about needs
        │
        ├─► Seller intent (e.g., "I want to sell...")
        │   └─► Wells: "Got it. Tell me about what you offer."
        │       └─► Shift to seller journey
        │
        └─► Job seeker (e.g., "Looking for work")
            └─► Wells: "I'm sorry to hear that. Tell me
                        about what you did..."
                └─► Empathy + exploration
```

## The Companion Loop

Once onboarding is complete, the relationship deepens:

```
┌──────────────────────────────────────────┐
│         THE COMPANION LOOP               │
│   (Post-Onboarding Relationship)         │
└──────────────────────────────────────────┘

    ┌─────────────────────────┐
    │ User has a need         │
    └───────────┬─────────────┘
                │
                ▼
    ┌─────────────────────────┐
    │ Wells anticipates       │
    │ (or user asks)          │
    └───────────┬─────────────┘
                │
                ▼
    ┌─────────────────────────┐
    │ Wells takes action      │
    │ (automatically or       │
    │  with approval)         │
    └───────────┬─────────────┘
                │
                ▼
    ┌─────────────────────────┐
    │ Result delivered        │
    └───────────┬─────────────┘
                │
                ▼
    ┌─────────────────────────┐
    │ Wells learns & improves │
    │ Trust deepens           │
    └───────────┬─────────────┘
                │
                │
                └──────► (Loop repeats)

Each loop:
• Increases trust
• Deepens relationship
• Makes Wells more valuable
• User becomes more dependent
• Companion status strengthens
```
